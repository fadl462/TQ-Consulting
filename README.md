# TQ Consulting — World-Class Website Prototype

A premium, responsive front-end prototype based on the supplied redesign brief and a review of the current TQ Consulting website.

## Direction
- Premium editorial aesthetic: deep navy, clean white, restrained TQ red accent
- Conversion-first information architecture
- Four clear solution pillars: Consulting, Learning, Coaching, Learning Technology
- Dedicated learning, certification, store and insight storytelling
- Motion: GSAP reveal animations, hover motion, marquee, floating cards
- Responsive desktop/tablet/mobile layout

## Run locally
Open `index.html` in a browser or serve the folder with any static web server.

## Notes
This is a design/prototype build, not an Odoo implementation. Image URLs use remote sources for presentation and should be replaced with final licensed brand photography/assets during handoff.

## Source inspiration / research
The information architecture reflects the current TQ Consulting offering visible on its website: consulting, learning and development, coaching, learning technology, public courses, e-learning, certifications, resources and store/contact journeys.
